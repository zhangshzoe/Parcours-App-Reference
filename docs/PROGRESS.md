# 按等级查看学习记录

更新：2026-10-04。当前实现位于 /coach → 我的 → 学习记录与技能证据。默认选择档案目标等级，也可单独查看 A1 或 A2；不会修改目标。切换法德后报告随当前档案切换。

## 统计口径

报告读取当前语言档案、所选等级的全部已保存历史，不使用最近 50 条列表作为汇总来源。GET /api/coach/progress?profileId=…&level=A1|A2 必须登录并验证档案归属，返回 private, no-store。查询位于同一受数据版本保护的 batch；读取不会封存到时考试、更新学习记录、调用 AI 或返回私人文字正文。

| 项目 | 含义与边界 |
|---|---|
| 微课 | 文字环节和整课完成分别按稳定课程 ID 去重。旧记录缺少快照等级时，从现有课程目录读取等级；无法归类的记录不猜测等级。 |
| 听读客观作答 | 已完成课程理解题、已提交精听选择题、已封存且已有结果的考试客观题；未作答不计错，尚在进行的考试不计。关键词听写和起点检查不并入此汇总。 |
| 首次与重复 | 按保存时间和稳定题目 ID 去重，同题跨专项与综合卷复用也不增加首次样本；已记录为熟悉材料的练习仍计重复。不同内容版本不自动创造新的题目样本。“首次”只表示首次保存该题的作答，不保证未用辅助：文字微课默认可查看译文和知识点，旧记录未保存是否查看。专项学习模式的作答单独统计，不并入此听读客观题汇总。 |
| 计时模式首次无系统辅助 | 仅计已封存的计时训练中，未被记录为熟题、此前也未在本报告的微课或精听中保存过同题作答，且该题没有辅助标记的听读客观题；分别列总数与答对数。学习模式题、微课与精听不并入。系统外帮助无法核验，少量题不构成等级判定。 |
| 法语需复看错题主题 | 从已保存的法语 A1/A2 听读客观题读取内容自带的知识点标签；微课旧记录使用保存的课程主题或目录中的同 ID 主题。只列至少有一次答错的前五个主题，显示错误次数和已答次数，包含重复练习，不包含未答题和私人回答正文。写作、口语没有可汇总的结构化错误标签，暂不推断薄弱点；单个错题不构成诊断。 |
| 写作 | 课程文字提交、考试已答写作任务、文字对话轮次分别列出。次数不代表质量成绩。 |
| 口语 | 成功识别并保存的会话录音和考试录音记录，采样毫秒数求和；包括尚未确认或未选作考试答案的重录。文字轮次即使带异常时长也排除；本机未提交录音及识别失败不在保存记录中。 |
| 口语完成证据 | 另列获得回复的音频轮次、已结束且含录音回复的会话、已封存考试的口语答案；不把录音保存直接等同任务完成。 |
| AI 参考反馈 | 已保存的对话轮次反馈和考试任务反馈。仅基于文字，不代表官方成绩或发音评估；会话结束小结未混入轮次数。 |
| 收藏与复习 | 明示为当前语言全部等级：历史复习项不一定保存独立等级，不能假装按 A1/A2 筛选。分别统计收藏、复习事件、到期项；另统计有上一轮事件且已到其计划时间后的再次作答，其中多少次保存了新情境回答、多少次自评“能运用”。首次收藏后的作答没有完整原定到期时间，不纳入延后统计。自评不是客观正确率。 |

零历史显示零记录及尚无客观作答；计时模式首次无系统辅助题少于三题提示数据不足。三题只是提示门槛，不是水平判定阈值。无论样本多少均不自动认证等级或预测通过率。录音采样时长不是有效开口时长；页面停留、计划预计时长、播放次数不作为学习时长。

## 页面与验证

报告位于“我的”页前部，四技能卡片在宽屏为两列、窄屏为单列。包括载入、错误、重试和主动更新；切换语言或等级后忽略旧请求响应，时间按档案时区显示。原课程最近记录与到期复习仍保留在下方。

- node scripts/verify-coach-progress.mjs：最终构建上通过。隔离临时数据库覆盖登录与归属、法德和 A1/A2、旧快照、同课去重、同题跨模式、未答与进行中排除、文字时长排除、录音一次计数、复习范围、到期后再次作答与新情境自评、无私人正文、无 AI 调用、无读取副作用和旧数据版本拒绝。
- node scripts/verify-coach-pwa.mjs：最终构建上通过。私人 API/RSC 不进缓存，公共资源路由、旧入口、鉴权与 no-store 检查通过。
- 浏览器已检查法语 A1 历史、A2 空历史、德语独立报告及切回后的记录恢复。360/390/430/1440px 均无页面横向溢出；截图见 screenshots/progress-*.jpg。
- 这些是本地隔离测试与桌面浏览器视口检查；未证明真实语音、人工审核、真实手机或大规模历史性能。
