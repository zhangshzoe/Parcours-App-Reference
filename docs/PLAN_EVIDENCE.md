# 每日计划的作答证据

2026-10-03，计划规则 evidence-v4。对应 PRD FR02：用真实近期练习提示巩固方向；同题重复练习不当作独立能力提升证据。

## 本轮发现和修复

原计划把精听题标记为“材料 ID:题目 ID”，考试复用题使用“exam-listen-材料 ID-题目 ID”。如果旧记录或并发记录中的 repeated 标记没有识别跨模式暴露，同一道题可重复进入首次客观样本。原统计还按模块扫描、只扫描近 14 天记录，可能使用后交答案作为首次结果，或将较早历史滑出窗口后的重做视为新的首次作答。

现在精听与考试共用题目标识；学习报告也调用同一标识函数。计划按实际提交/完成时间汇总全部当前等级历史，先去重，再仅选近 14 天的首次客观作答。重复标记仍是保守排除条件，并保留对应题目已接触的身份。较早历史始终参与去重。同一 ID 的版本更新不会自动制造独立能力样本；真正新题须使用独立内容身份。

课程理解题使用同样的首次完成时间规则。近期活动和能力样本含义不同：有实际回答的重复练习仍可计入近 7 天活动，但不成为新的首次客观样本。小于 3 个独立客观样本时，不能生成基于错题比例的巩固理由。未提供音频发音评分、等级推断或通过概率。

空白精听提交可以查看原文，但不再算近期已作答活动、不完成每日精听任务，也不阻止该材料重新成为当天候选。仅有听写输入时，计为近期听力活动并可完成任务；不会混入选择题首次样本。这是活动完成判据，未声称听写输入即正确或已经听懂。

已有日计划在规则版本变化时重新生成未完成部分，保留有效已完成任务并扣除其分钟预算；不会修改历史作答、试卷结果或复习安排。无需数据库迁移。

## 实际验证

- npx tsc --noEmit --incremental false：通过。
- npm run build：通过。
- node scripts/verify-coach-plan-evidence.mjs：通过。法德 A1/A2 四组合，各验证精听先提交、考试先提交、首次记录早于窗口；故意使用 repeated=false 的历史/并发情形，验证不能重复计数。检查报告首次结果一致、提交顺序、重复标记已有但原始记录缺失、时间边界、未来时间不进入样本、技能分离和输入不被改写。隔离 API 检查空白任务仍待做、听写活动计入但不成为选择题样本、课程提交顺序、规则升级后的完成和预算保留。
- node scripts/verify-coach-plans.mjs：通过。三目标、四预算、近周覆盖、额度/服务降级、专项完整时限、复习、恢复和重排。
- node scripts/verify-coach-progress.mjs：通过。跨模式首次/重复、用户/语言/等级隔离、空历史、旧快照、录音与文字区分、只读统计。

上述测试使用一次性本地 Miniflare 数据库和明确的合成历史，不操作预览账号历史，不调用外部 AI，也不证明真实音频或真机可用。本轮没有 UI 结构改动，未重复四宽度或真机检查。完整 PRD 的真实服务、内容人工审核、真机、重新认证、官方资料等验收仍未完成。
