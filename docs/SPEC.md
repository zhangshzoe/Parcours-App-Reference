# Parcours Coach v0.1 实施规格

依据：当前任务 `语言学习/docs/PRD.md`（2026-10-02）及用户原始完整规格。PRD 为完整验收范围，本文件仅记录实现定位，不缩减要求。

在现有项目 `/coach` 增量实现手机优先的法语／德语 A1、A2 学习教练。旧 `/` 页面、旧数据和既有迁移保留。新功能采用 `coach_` 表隔离；不自动迁移未审计的历史成绩，不把旧 100 课扩展视作完整等级教材。

五个导航：今日、课程、听说、考证、我的。中文界面、法德独立档案与目标、可解释每日计划、真实听说服务、复习、四技能考试训练、导出删除与 PWA 均在最终范围内。以完整 PRD 的 AC01—AC14 逐条验证。

当前授权边界：本地开发与测试。不公开发布、不购买服务、不删除生产数据、不把真实私人数据传给未经授权的新服务。未配置 AI、未人工审核、未真机验证、未部署分别列出，不用模拟成功代替真实验收。

技术：沿用 React／TypeScript、Vinext、Tailwind、D1／Drizzle。所有私有接口校验平台身份及记录归属；客户端不包含题目答案；提交、复习与计划遵守幂等、版本及服务端时间规则。
