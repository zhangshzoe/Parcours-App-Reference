# 收藏与复习库

2026-10-03。对应 PRD FR07 及“我的”生词与错题入口。

“我的 → 查看全部收藏”展示当前语言所有等级、所有复习时间的收藏。生词、句子、常用表达、考点与错题可分别筛选；可选择已到期或尚未到期，并搜索目标语言、中文解释、来源标题。搜索兼容大小写与 Unicode 组合字符；每次展示 20 条，可继续展开更多。

未来收藏可以阅读，不能通过此入口加入到期练习。浏览和搜索不写入事件、不更改日期、阶段或成绩。复习按钮只传递当前筛选结果中的到期 ID，现有复习调度与幂等接口保持不变。到期判断使用最近一次 learning 响应的服务器时间；进入页面后没有实时倒计时。

收藏详情展示保存时的内容及已存在的词汇例句、复数、变位、发音提示，不用当前版本覆盖旧快照。来源标题随快照保留。考点收藏可能来自主动收藏的正确题，因此不宣称所有考点都是错题。

法德逐轮口语及考后写作／口语反馈现在允许学习者主动收藏 AI 标为“任务尚未完成”的建议。这类卡归入“考点与错题”，保存原回答、技能、考点、任务版本及来源 ID；先让学习者回想遗漏的行动，揭示后再显示建议。明确错误和可选表达仍归入“常用表达”；证据不确定的反馈不能收藏。收藏不代表 AI 判断经教师确认，也不自动证明已在新情境掌握。

历史考点卡把题干和解析存放在同一中文字段。复习时不猜测分隔位置，不在揭示前显示该字段；先提示回忆考点，用户点击后显示完整参考内容。这是回忆卡，不是客观重新答题；不会产生新的考试正确率。其他词句卡继续以中文提示回忆目标语言。

首批法语 A1/A2 情景口语、口语专项和写作专项的任务遗漏卡，保存一条与原题同类但材料不同的原创新情境。到期时先用法语写本次回答，才可揭示原反馈建议并自评；回答和当次情境随复习事件保留。自评只安排下次复习，不据文字长度或与建议的相似程度判语言能力。旧卡和德语卡保持原有回忆流程；历史收藏不被自动改写。

迁移 `0016_careful_romulus.sql` 仅为复习事件增添可为空的回答和情境字段；初次实现时尚未在本地预览库或生产库应用。隔离数据库中，空回答被拒、同一请求重放不重复保存、改变已提交回答被拒，旧复习无回答仍可提交。类型检查、构建、复习库、旧课程复习、口语、考后反馈、自由练习及隐私导出／删除回归通过。没有教师或真实 AI 对迁移回答进行评价，也没有真机 UI 验收。
