# 句型拆解与仿写

2026-10-03。对应 PRD FR03：语法服务于表达、法德独立教学、适合等级的引导。

现有 16 节微课都有简短知识点说明。本次为四节增加可展开的“原句 → 变换 → 仿写 → 一种参考表达 → 自查”，补足从规则摘要到实际写作的支架；不是增加四节课，也不是完整等级教材。

| 课程 | 独立知识点 | 仿写用途 |
|---|---|---|
| 法语 A1 说明一天的时间安排 | fr.negation.present-ne-pas | 围绕现在时动词构造 ne／n’…pas，说明不做的日常活动 |
| 法语 A2 说明居住问题并请求帮助 | fr.future.etre-availability | 对照 suis／serai，以未来时间段说明可到访安排 |
| 德语 A1 描述起床和上课的时间 | de.separable.present-v2 | 更换句首时间成分，保留变位动词第二位及可分前缀末位 |
| 德语 A2 协调同伴的时间 | de.weil.modal-position | 在标准书面语 weil 从句中使用 arbeiten muss，并提出替代时间 |

每份补充讲解有独立 ID、版本 1、语言、等级、知识点、课程版本与原文锚点。服务端仅返回匹配课程的讲解；原句不匹配时拒绝绑定。它是当前补充资料，界面明确这一身份，不声称它属于历史作答时冻结的内容。原课程 v1、问题答案、文字结果、媒体关联与整课完成条件没有更改。

参考表达默认折叠；已有中文开关同时控制新例句与参考译文。中文教学解释保留，以符合中文界面定位。没有第二个编辑器，用户在本课原有写作框完成仿写并保存；不自动填入参考答案，不逐字匹配开放表达，不为展开内容或自查生成分数。
