# 发音观察、跟读与复习

更新：2026-10-03。法德 A1/A2 共 16 份独立发音提示，关联现有 16 节微课；是首批课程的补充教学，不是完整语音课程。每份包含语言、等级、稳定 ID、版本、知识点、原句定位、解释、练习任务、自查和来源状态。AI 辅助编写，未经过教师人工审核；未产生发音分数。

## 内容覆盖

| 语言等级 | 四节对应重点 |
|---|---|
| 法语 A1 | vous habitez 联诵；du/vous 元音区别；combien/prends 的不同鼻化元音；une amie 辅音衔接 |
| 法语 A2 | mon/train 鼻化区别；nous avons 联诵；约时间的意群；chauffage 词尾 e |
| 德语 A1 | ich 的 ch 与 sch；zwölf 的 ö；nach 的 ch；sieben/beginnt 长短元音 |
| 德语 A2 | Schlüssel 的 ü；Können/fünf 变元音；Bus/früh 音色与长度；理由与替代方案的句子重点 |

例子取自已有原创课程句子，不复制外部录音、歌曲或样题。说明只覆盖所举具体语境，不宣称所有词遵循同一发音规则。源代码位于 lib/coach/pronunciation.ts，类型位于 pronunciation-types.ts。

## 学习路径

课程进度页可展开“发音观察与跟读”，了解本课重点并进入关联精听。精听仍先听、作答、提交，随后才返回原文及当次保存的发音提示；逐句按钮复用现有播放逻辑，只合成关联句子的文本，不把音标和中文提示送入 TTS。可用原有倍速、循环、本机录音试听，随后收藏句子和提示进入复习。

音频服务未配置时，保留教学文字并禁用播放；没有模拟声音或假波形。跟读录音仍只保留在本机当前页面，不上传、不计保存口语或成绩。自查问题不产生评分、正确率或课程完成事件。整课的音频/录音交流门槛不变。

## 版本与历史

发音提示是独立版本的附加内容（v1），不是试题或音频正文更新：原课程版本、材料正文/题目版本、考试题目 ID 与规则保持不变。课程概览显示与课程语言/等级/版本相符的当前附加提示；新精听开始时另将完整提示冻结进原有材料快照。旧精听快照没有提示时返回 null，不补写历史；其原题目、原文、计时、成绩不变。没有数据库迁移。

提示中每个 example 必须在指定句子出现，否则新练习创建失败，避免点击时播放不相干句子。材料与课程语言、等级和版本同时匹配；目录与精听未提交结果不包含补充原句。考试目录不导入这些提示。

用户收藏句子时，将当次提示快照存入已有复习 payload。同一来源仍只有一条收藏：重复收藏不重置阶段、日期或 revision；旧收藏缺少提示时，只有用户再次明确收藏才补入，已有提示版本不被覆盖。查看复习答案后可展开提示，自查而不计分。导出保留自己的复习 payload；材料内部快照仍按既有隐私规则裁剪。

## 教学参考核对

以下是教学方向参考，不是本课程已获外部机构或教师审核的证明。核对日期 2026-10-03。

- [UT Austin 鼻化元音](https://laits.utexas.edu/fi/html/pho/10.html)：读取页面正文；用于核对鼻化与独立鼻辅音的区别及元音类别。具体例子使用本课句子。
- [UT Austin 联诵](https://laits.utexas.edu/fi/html/pho/12.html)：读取正文；用于核对代词与动词的连接语境。未将页面概括扩大成所有场景的规则。
- [UT Austin 语音符号](https://www.laits.utexas.edu/fi/html/pho/02.html)、[词尾 e](https://www.laits.utexas.edu/fi/html/pho/11.html)、[句子重音](https://www.laits.utexas.edu/fi/html/pho/03.html)：正文可访问；支撑音标、弱读和意群教学方向。
- [Goethe 发音教学](https://www.goethe.de/ins/it/de/spr/wdl/ded/aut.html)：正文可访问，涵盖 ich/ach、变元音、辅音、词与句子重音的教学入口。本轮未观看或复制视频，未核验音频示范。
- [DW 长短元音资料](https://www.dw.com/downloads/26361370/lektion5-lehrer-aussprache.pdf)、[DW 字母与元音资料](https://www.dw.com/downloads/26294183/lektion1-lerner-aussprache.pdf)：检索返回相关正文摘录，直接打开受限；未取得完整 PDF 的逐页核验。作为候选教学参考，正式内容审核需补齐原文和例词逐项确认。Goethe 工作表直接打开超时，也未视为已完整核验。

人工仍需审核全部音标、例词、中文解释、难度与实际合成音频。来源可访问与机器结构通过不能代替教师审核。
