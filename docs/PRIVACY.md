# 学习数据导出与删除

更新：2026-10-04。导出与按范围删除已在本地实现，隔离数据库和迟到请求测试通过。删除弹窗已补做浏览器四尺寸的范围、错误确认文字与取消检查；未在实际账号执行删除。真实手机、重新认证能力仍未验证，完整隐私验收未完成。

## 导出

法语／德语教练或英语听说的“我的”页均提供两种范围：当前路线记录，以及全部应用记录。接口为 `POST /api/coach/privacy`，请求 `{action:'export',scope:'all'|'fr-FR'|'de-DE'|'en-US'}`。服务端从认证身份确定用户，不接受客户端 userId。

当前法语或德语导出覆盖 24 张 coach 表；当前英语导出覆盖 6 张 english 表。全部导出还含旧版本的 7 张表和 app_data_controls 中属于当前用户的最小数据版本与最近清理回执，共 38 类。包括语言档案、目标历史、文字与微课步骤关联、每日计划、收藏与复习、口语会话和逐轮记录、原始与修正转写、精听、起点检查、考试作答、表达反馈、调用元数据以及旧版课程／草稿／自评／内容报告。

查询和列名来自服务端固定允许列表；每张表按所有者／所属档案筛选，调用表额外校验自身 user_id。所选范围的表使用同一个 D1 batch 读取，不沿用旧首页最近 500 条的展示限制，不使用分页截断。导出是读取操作，不封存到时的训练或重算结果。空记录返回空数组与零条汇总。

下载格式为 UTF-8 JSON，包含 format、version、exportedAt、scope、当前账号信息、范围说明、分表数量与记录。JSON 字段转换为结构化值；无法解析的历史 JSON 保留原始字符串并标为 unparsed-json。时间戳保持 UTC 毫秒，日期／时区保留原值。

文件包含自己的作答和已提交结果。冻结教学快照只导出内容 ID、版本及必要引用；不导出未提交题目的标准答案、隐藏听力原文或内部题库快照。正在作答的训练不因导出而开放结果。导出的 JSON 是备份资料，当前不提供导入恢复功能。

应用未持久化原始录音／合成音频，故没有音频文件可附加；保留的原始转写、确认版本、修订记录和录音时长分别导出，录音时长不包装为有效口语时长。法语考级口语页面在首次录音、考后重试和文字反馈前分别说明发送给 OpenAI 的内容与时机；仅保存写作重试文字不会发起 AI 调用。未上传的浏览器输入／录音、供应商自身的记录、密码和服务密钥不在范围内。

英语会话创建时尚未取得录音处理同意，新会话的 `consent_version` 因此先记为 `not-obtained`；收到带正确同意版本的录音请求并通过服务端前置校验后，才更新为 `english-audio-v1`。历史会话的该字段可能只表示当时适用的说明版本，不能单独证明用户上传过录音。导出另给出 `audioConsentRequestRecorded`：仅当同账号会话有已保存的录音请求元数据才为 true；它证明服务端收到符合版本要求的请求，不证明设备上具体点击过程。旧记录不追溯改写。

接口要求登录、同源请求和 JSON 格式，严格校验 action／scope，限制请求体为 1000 字节。响应使用 attachment、private no-store、Vary Cookie 与 nosniff。文件直接返回当前浏览器，服务器不创建导出对象、公开下载 URL、后台作业或永久副本。客户端下载完整 JSON 并核对格式、范围与汇总后才发起下载；可取消等待，离开模块也会中止请求。提示只声称“请求下载”，不替浏览器宣称保存完成。

没有人为省略历史记录的数量上限；非常大的单用户导出仍受运行时内存／响应限制，尚未进行大规模压力测试。失败不返回被截断的成功文件。未来若需要流式导出，必须同时解决一致性与完整性，不能仅按表分页后声称是同一快照。

## 验证

`scripts/verify-coach-privacy.mjs` 在隔离内存数据库迁移全部表，并自动比较导出定义和 SQLite 表／字段。新增表或字段时测试必须要求明确覆盖决策。

测试样本覆盖同一用户法德档案、另一用户档案及全部子表；旧版事件为 601 条，超过现有首页的 500 条限制。断言全部记录数与汇总一致，语言／用户隔离、Unicode／JSON／原始与确认转写保留、已提交结果保留、未提交题库信息不泄露、空账号、无外部调用、无副作用、鉴权、跨站请求、未知字段、非法范围和过长请求。缺失确认字段的删除动作返回 400；有效删除需通过下述独立确认流程。

本地浏览器实际点击“下载学习数据（JSON）”，接口返回 200。随后在下载目录找到 48,024 字节 JSON，解析验证格式、fr-FR 范围、23 类数据、35 条记录及汇总一致。仅记录元数据，实际下载文件没有复制进代码仓库。

浏览器工具等待下载事件时超时，之后绑定同一标签与读取标签列表也出现连接失败；已查阅工具故障说明，没有重启正在运行的开发服务、没有重复点击下载。页面入口的 DOM 已观察到，但本轮尚未保存截图或完成四尺寸新面板验收。不能把服务端／文件验证替代这些 UI 验证。

## 删除流程与范围

“我的”页支持仅当前法语／德语教练数据，或全部应用学习数据（包括旧版全部语言）。先显示认证账号、范围和各类记录数量，再要求输入对应确认文字和勾选不可撤销说明。预览数量可能变化，执行时以该用户和范围内的全部记录为准。确认只在五分钟内有效，绑定账号、范围和数据版本；新确认使旧确认失效。过期确认不会执行删除，确认行最多每用户一条，重新准备或成功删除时替换／清理；尚无独立定时过期行清理任务。

接口 action 为 prepare-delete、delete、deletion-status。保留现有登录身份、同源、JSON 和请求体校验；客户端不能指定另一用户。客户端超时只显示结果尚未确认，可以查询回执或重试同一个请求，不自动发起另一删除。相同请求并发或在成功后重试均返回原回执，不再次清理后来新建的记录。

服务端一个原子 D1 batch 内二次核对版本与确认令牌有效期、递增版本、按外键子表顺序删除所选记录并保存回执。任一步失败整批回滚。仅当前语言删除覆盖 23 张教练表，保留另一语言和旧版；全部删除覆盖 30 张业务表。应用保留 app_data_controls 的用户标识、数据版本、最后删除请求 ID、范围和时间，用于阻止旧请求及保证重试安全；该元数据可导出。app_data_guards 仅事务内临时使用，提交后无行；确认令牌不导出。

## 防止删除后重新写入

旧版与教练接口都携带 X-Parcours-Data-Revision。档案首次读取提供当前版本；旧页面遇到版本变化必须刷新，不把旧草稿自动视为新内容。删除后缺少版本头的写请求也拒绝；GET 无头允许刷新引导，不能据此直接写入。

每次业务 SQL 读取／写入／批处理均在同一事务检查数据版本。已经发出的 AI 请求完成时也经过此检查，因此迟到的识别文本、对话反馈或合成音频不会恢复已删除数据。服务端已经发往供应商的处理不能据此撤回；本地删除不保证取消供应商请求或费用。事务保护每次额外执行两条临时 SQL，尚未完成生产并发与费用压力测试。

版本按用户递增，清理一种语言后，该用户所有已打开页面都需刷新。另一语言记录保留，但其正在处理的请求也被拒绝继续写入；尚为 running 的调用由现有 90 秒超时恢复规则处理，短暂期间可能提示处理中。浏览器其他标签内存不能由服务端抹除，已返回的内容不能撤回；界面明确提示这一范围。

## 仍需完成的隐私验收

当前认证只提供用户身份，没有可验证的重新认证时间；确认文案／短期确认令牌不等于重新登录。PRD 的敏感操作重新认证要求仍未满足，需接入身份提供方支持的可验证 step-up，再作相应验收。

删除仅针对应用保存的学习记录，不注销外部登录账号，不删除用户已下载文件、供应商或备份中尚未核实的留存。原始音频默认未在应用持久化；以后若加入保存音频或导出对象，必须扩展清理范围、生命周期与测试。公开交付前仍需隐私范围、服务商留存与实际 UI 审核。
